# landing-spabekov

Лендинг: Детский центр развития


Тема: Детский центр развития (кружки, возраст, запись).
Автор: Спабеков Мейрбек


[Сайт](https://ТВОЙ_ЛОГИН.github.io/landing-spabekov/)

##Что реализовано по неделе №2:
- **Семантика HTML5:** использованы теги `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- **Структура:** реализованы 4 логических блока (шапка, о нас, кружки/услуги, форма записи).
- **Формы:** настроена форма обратной связи с полями Имя, Email, Сообщение (использованы `label` и атрибут `required`).
- **Доступность и SEO:** соблюдена строгая иерархия заголовков `h1-h3`, все картинки имеют атрибут `alt`, настроены мета-теги `description` и `viewport`, добавлен базовый `favicon`.
- **Адаптивность (CSS3):** без использования фреймворков настроены стили и медиа-запросы. Сайт корректно отображается как на ширине 1280px, так и на смартфонах от 375px.



Что реализовано из новых возможностей по неделе №3:
1. **CSS Variables (`:root`)** — для управления цветами и отступами.
2. **CSS Nesting** — нативная вложенность селекторов.
3. **Функция `clamp()`** — для плавной адаптивной типографики и отступов (`--fs-h1`, `--fs-h2`, `--spacing`).
4. **Container Queries (`@container`)** — карточки кружков, услуг и цен перестраиваются (1, 2 или 3 в ряд) в зависимости от ширины контейнера.
5. **Псевдокласс `:has()`** — блокирует прокрутку `body`, если открыто мобильное меню (`body:has(.main-nav.open)`).
